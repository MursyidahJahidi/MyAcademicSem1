# Reflection
Doing lab 1 was a really meaningful experience for me because it was the first time I actually building logic gates on real breadboard. I learned that staying organized is key, so I followed the color code by using red for all Vcc connections, black wire for all ground connections, blue wire for all input switches, and yellow wire for all intermediate signal connections, which helped me avoid confusion. I also learned how important IC orientation is, bacause placing the IC the wrong way could damage it. This made my partner and I to be more careful during the lab. The most interesting part of the lab was testing the circuit and observing the LEDs on the digital kit. Seeing the LED turn red for logic High (1) and green for logic Low (0) made it easier to check whether the circuit was working correctly according to the truth table. It felt really satisfying shen we managed to get the correct result on the first try.

Overall, realizing that a complex circuit made up of several gates could function the same as a single logic gate really helped me understand digital logic in a more practical way. I hope I can gain more hands on experience like this in future labs to improve my understanding fo what I learned in class.
